# 检查报告模板

本模板供 forge--check-all-skills 使用；查看最佳实践时不必生成检查报告。花括号内容是待填写的模板字段，不代表现有文件或结果。

```text
Skill 检查报告
- 技能名称：{skill-name 或检查范围}
- 静态检查：{pass / error}
- 人工内容核对：{pass / error / evidence-required}
- 统计：静态通过 {n} / 静态失败 {n} / 人工待验证 {n}
- 检查内容：{名称与用途、元数据、资源、README、交付要求}
- 发现与处理：{具体文件、问题、修正或建议}
- 验证：{实际命令、输入与输出；未运行的项目单列}
- 限制：{外部服务、凭据、项目别名及未覆盖范围}
```

不得用静态检查成功宣称外部集成已通过；未获得修改授权时只报告问题。修改后重新检查并交付实际结果。
