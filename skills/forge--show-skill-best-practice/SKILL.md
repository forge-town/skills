# Skill 编写最佳实践

说明怎样编写可复用、可验证的技能，并指出规则适用的边界。

1. 按 [最佳实践](references/standard.md) 展示与当前问题有关的规则、理由和例子。
2. 需要目录示例时读取 [结构定义](references/anatomy.json) 与 [完整样例](best-practice-examples/forge--show-sample-best-practice/SKILL.md)。
3. 交付前按 [完成清单](references/checklist.md) 核对说明是否清楚、引用是否真实。
4. 用户要求实际检查时使用 `forge--check-all-skills`；仅查看最佳实践不自动修改文件、提交 Git 或运行修复。
