# 实现计划编写检查清单

产出计划前后逐项确认：

- [ ] 已确认输入前提成立：存在用户批准的设计文档、明确范围、优先级和约束
- [ ] 已先完成文件结构规划，明确哪些文件创建、修改或拆分以及各自职责
- [ ] 已把工作拆成最小可执行任务，每个任务都能独立开始并独立验收
- [ ] 每个任务都写明具体文件路径、修改目标、所需上下文和实现边界
- [ ] 每个任务都提供明确验证方式，包括命令、预期结果和完成标准
- [ ] 计划内容对低上下文执行者足够自洽，不依赖口头补充或隐含背景
- [ ] 已显式纳入 DRY、YAGNI、TDD、频繁提交等执行约束，而非只写功能步骤
- [ ] 已将最终计划保存到约定路径，并保证命名与主题清晰可追溯
