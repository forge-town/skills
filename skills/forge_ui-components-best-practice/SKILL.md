# UI 组件最佳实践

## 使用说明

1. 阅读 [组件库规范指南](references/standard.md)，了解何时必须使用组件库组件
2. 对照 [检查清单](references/checklist.md) 逐项验证代码
3. 参考 [最佳实践示例](best-practice-examples/) 了解标准写法

**重要：** 遇到标准 UI 场景时，必须使用组件库组件，禁止直接使用原生 HTML 元素
