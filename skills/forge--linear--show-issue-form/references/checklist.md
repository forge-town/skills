# 表单交付清单

- [ ] 已生成并打开实际界面，提供 docs/ 下 HTML 链接；没有以写正文代替唤起界面。
- [ ] 黑白灰、单层分节、无嵌套卡片；桌面与窄屏均可填写和查看映射。
- [ ] 空白或明确要求的预填内容正确；未知事实与精确参数未编造。
- [ ] 字段提示和当前类型条目增删正常；Feature 的 BR 删除不静默重绑。
- [ ] 对应类型的必填与关系提示可定位；结构成功仍说明内容待 Review。
- [ ] 实测正文与 Markdown 一致、JSON 往返可编辑、草稿恢复及导出可用。
- [ ] 更新过源文件时已重建独立模板，图片附件限制已说明。
- [ ] 没有未经授权写入 Linear；未运行的外部流程单列。

字段与章节指导说明统一放在标签旁的“？”气泡中，悬停、键盘聚焦或手机点按时显示；输入框下不常驻说明文字。
- [ ] 已验证 Feature 与 Bugfix 的不同字段、独立草稿、导出；切换不混入另一类内容。

- [ ] 只提供一个前端入口，固定页头可切换 Feature／Bugfix，URL 不变；Feature 使用背景介绍与目标预期。

- [ ] Feature 不显示操作入口与交互契约，正文不生成交互表；具体操作写入验收案例。Bugfix 显示业务规则和验收案例，不再显示回归验证。

- [ ] 表单与正文没有独立前端变更／技术说明；旧内容仅归档，不再作为必填或 Review 缺项。

- [ ] 验收只写必要前提、具体输入与操作、预期结果，不再要求执行元信息或完成条件章。
- [ ] Header 的“查看示例”可切换 Todo List 与类幸存者两个完整 Feature，并打开实际本地原型；查看不覆盖草稿，确认填入可恢复备份，验收区无重复入口。示例不等于真实产品验收通过。

- [ ] 两类表单的摘要三项可填写、校验、导入导出，表单中在基本信息后显示，正文从摘要开始；旧摘要可恢复，当前值和明确清空不被覆盖。

- [ ] 标题在标题栏，基本信息在原生 Properties，正文从摘要开始；检查报告没有把正文缺基本信息章当问题。未映射项未冒充原生字段，未清空未知属性。

- [ ] 任务不再重复输入输出条件或独立业务规则，正文和预览均没有任务表格，内容没有丢失或合并。

- [ ] 任务与案例均以中文前提条件／操作／预期结果呈现，AC 使用 given／when／then，旧固定输入和预期迁移无丢失，当前明确清空不被旧值覆盖。

- [ ] 没有重复“目标预期”标签、业务规则章、用户流程章、英文 Given／When／Then 或重复步骤表；任务与案例的关联和材料迁移无丢失。


- [ ] 表单和生成正文没有参考资料栏目、固定链接字段、键值对集合或“无”的占位。

- [ ] 人物正文使用标准 Markdown 斜体，HTML 预览同步；标题、原生属性、链接、代码和字面输入不变，无人物 HTML 标签写入 Linear。
