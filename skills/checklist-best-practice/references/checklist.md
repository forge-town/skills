# Checklist 合规检查清单

## 通用结构
- [ ] 1.1 文件以 `# {名称} 检查清单` 或 `# {名称} 完成清单` 作为标题
- [ ] 1.2 所有条目使用 `- [ ]` Markdown 复选框格式
- [ ] 1.3 条目总数 ≤ 30（超出须拆分为子清单）

## 条目可判定性
- [ ] 2.1 每条描述可回答 Yes/No，禁止模糊表述
  - ✅ 正确：`- [ ] 文件名格式为 {feature}Dao.ts（如 usersDao.ts）`
  - ❌ 错误：`- [ ] 命名要规范`（无法判断）
- [ ] 2.2 每条至少附一个代码/文件名示例（正确示例或错误示例）
  - ✅ 正确：`- [ ] Props 类型已导出（\`export type ButtonProps\`）`
  - ❌ 错误：`- [ ] Props 类型已导出`（无示例）

## 规范 Checklist 额外要求（-best-practice 类）
- [ ] 3.1 使用 `{大类}.{小类}` 编号格式（如 `1.1`、`2.3`）
  - ✅ 正确：`- [ ] 1.1 组件以独立文件夹形式存在`
  - ❌ 错误：`- [ ] 组件以独立文件夹形式存在`（无编号）
- [ ] 3.2 相关条目已归入 `## 分类` 节，每节 ≤ 8 条
- [ ] 3.3 包含 `## Bad Case 确认` 节，列出不得出现的反模式
  - ✅ 正确：`- [ ] ❌ 不存在使用 export default 的桶导出文件的情况`
  - ❌ 错误：无 Bad Case 节

## 操作完成 Checklist 额外要求（动词型 Skill）
- [ ] 4.1 条目描述使用"已完成"语态，而非命令式
  - ✅ 正确：`- [ ] 目标目录已递归扫描（包含所有子文件夹）`
  - ❌ 错误：`- [ ] 扫描目录`
- [ ] 4.2 条目数量 5-8 条（过多须拆分操作步骤）

## Bad Case 确认
- [ ] ❌ 不存在使用"应该"、"需要"、"建议"等模糊词的条目
- [ ] ❌ 不存在无任何示例的纯文字规则条目
- [ ] ❌ 不存在超过 10 条不分组平铺的规范 Checklist
