# Subagent 执行检查清单

每次执行本技能时逐项确认：

- [ ] 已确认存在用户批准的设计文档和可执行实现计划
- [ ] 已提取全部任务全文、上下文和验收标准，并整理为明确待办列表
- [ ] 已判断任务之间是否足够独立，适合交给全新子代理并行或串行执行
- [ ] 已为每个子代理提供完整任务文本、相关文件路径和必要背景，避免依赖主会话隐式上下文
- [ ] 已在每个任务完成后先做规格一致性审查，再做代码质量审查
- [ ] 已在审查发现偏差时要求返工，而不是直接带病合并结果
- [ ] 已在任务之间同步最新上下文，避免后续子代理基于过期状态继续工作
- [ ] 已在全部任务完成后做最终集成验证，确认实现与计划一致
