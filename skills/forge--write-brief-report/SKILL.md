# 工作简报

按真实工作产出写简报；未指定时间时默认当天日报，给出时间范围时汇总该时段。

1. 开始前读取 [时间与会话取证](references/session-sources.md)，确定项目、会话、时区及起止时间。
2. 按 [简报流程](references/workflow.md) 核对实际结果、合并重复事项，保留完成状态和必要限制。
3. 交付前按 [完成清单](references/checklist.md) 确认时间范围、内容与覆盖情况。

默认在当前对话交付简洁正文；用户要求文件时保存到项目 docs/。写简报不授权发送消息、发布文档、修改任务或创建定时器。
