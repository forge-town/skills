# 简报完成清单

- [ ] 已确认项目、会话与时区；未指定时间时默认当天，指定时间时严格采用该时段。
- [ ] 已明确起止边界与核验截止时刻，正确处理包含结束日期、跨日与尚未结束的范围。
- [ ] 已读取所选会话在目标时段的内容并核对分页，未按会话创建日期遗漏跨时段工作。
- [ ] 已为成果保留时间、会话/turn 定位与实际结果，不把计划、标题或助手承诺当作成果。
- [ ] 已按事项去重，取目标时段内最后有结果支持的状态，不借用区间外的完成结果。
- [ ] 已区分实现、发布与验收，未虚构工时、比例或客户接受结论。
- [ ] 已形成可直接使用的简报正文；默认不附计划，多日时段不强制拆成多篇日报。
- [ ] 已在正文外说明覆盖缺口；保存的文件位于项目 docs/，没有泄露凭据或内部思考。
- [ ] 已遵守本次汇总授权，没有自动发送、发布、改 Issue 或创建定时器。
