## 迁移前准备

### 环境检查
- [ ] 项目已安装 React 和 TypeScript
- [ ] 存在 `components/` 目录
- [ ] 已创建 `components/icons/` 目录
- [ ] 配置好路径别名（如 `@/components/icons`）

### 资源检查
- [ ] 已识别所有需要迁移的内联 SVG 位置
- [ ] 已记录每个图标的用途和上下文
- [ ] 已备份原始代码（如使用 git）
- [ ] 已阅读命名规范和组件模板

## 迁移步骤

### 步骤 1：提取 SVG 代码
对于每个需要迁移的图标：

- [ ] 在业务组件中定位 `<svg>` 标签
- [ ] 提取完整的 SVG 代码（包括所有属性和子元素）
- [ ] 记录原始的 viewBox 值
- [ ] 记录原始的 width、height、fill、stroke 等属性
- [ ] 确认 SVG 结构完整（无缺失的标签）

### 步骤 2：创建图标组件

#### 基本检查
- [ ] 在 `components/icons/` 目录下创建新文件
- [ ] 文件名采用 PascalCase 格式（如 `ArrowRight.tsx`）
- [ ] 组件名与文件名完全一致
- [ ] 添加 TypeScript 类型定义

#### 属性处理
- [ ] 移除 `xmlns` 属性
- [ ] 将 `width` 转换为 prop，默认值为 24
- [ ] 将 `height` 转换为 prop，默认值为 24
- [ ] 将 `fill` 转换为 prop，默认值为 'currentColor'
- [ ] 如果存在 `stroke`，转换为 prop
- [ ] 如果存在 `strokeWidth`，转换为 prop

#### 结构处理
- [ ] 保留 `viewBox` 属性
- [ ] 保留所有 path、circle、rect 等子元素
- [ ] 保持原始的坐标和路径数据
- [ ] 添加 `...rest` 属性透传

#### 导出
- [ ] 使用默认导出：`export default ComponentName`
- [ ] 文件末尾无多余空行

### 步骤 3：更新业务组件

#### 导入替换
- [ ] 删除原有的内联 SVG 代码
- [ ] 添加导入语句：`import IconName from '@/components/icons/IconName'`
- [ ] 替换为 `<IconName />` 组件

#### 属性迁移
- [ ] 将原始的 width 值作为 prop 传递
- [ ] 将原始的 height 值作为 prop 传递
- [ ] 将原始的 fill 值作为 prop 传递（如果不是默认值）
- [ ] 如果原始有 className，迁移到新组件
- [ ] 如果原始有事件处理（如 onClick），迁移到新组件

#### 验证替换
- [ ] 确认原 SVG 的所有可配置属性都已迁移
- [ ] 确认组件在页面中的位置和样式保持一致
- [ ] 确认交互行为保持一致

### 步骤 4：清理冗余代码
- [ ] 删除业务组件中的内联 SVG 代码
- [ ] 删除未使用的 SVG 相关 import
- [ ] 删除临时文件或注释掉的代码
- [ ] 格式化代码，保持一致性

## 常见问题

### 问题 1：图标显示不正确
**可能原因：**
- viewBox 设置错误
- path 数据不完整
- fill/stroke 属性丢失

**解决方案：**
- [ ] 检查原始 SVG 的 viewBox 是否正确复制
- [ ] 检查 path 数据是否完整
- [ ] 检查 fill 和 stroke 属性是否正确设置

### 问题 2：图标大小不一致
**可能原因：**
- 默认值不统一
- 单位使用不一致（px vs rem）

**解决方案：**
- [ ] 统一所有图标的默认 width 和 height 值为 24
- [ ] 避免混用 px 和 rem，选择一种单位

### 问题 3：颜色不正确
**可能原因：**
- fill 默认值不是 'currentColor'
- 父元素没有设置 color
- 图标本身有硬编码的颜色

**解决方案：**
- [ ] 确保 fill 默认值为 'currentColor'
- [ ] 检查父元素的 color 属性
- [ ] 移除硬编码的颜色值

### 问题 4：TypeScript 类型错误
**可能原因：**
- 类型定义不正确
- props 名称拼写错误
- 使用了不存在的属性

**解决方案：**
- [ ] 检查 IconProps 接口定义
- [ ] 确认使用的属性名与接口一致
- [ ] 使用 ...rest 透传未知属性

### 问题 5：性能问题
**可能原因：**
- 图标组件没有正确导出
- 每次渲染都重新创建组件
- 没有使用 memo 优化（可选）

**解决方案：**
- [ ] 确保使用默认导出
- [ ] 考虑使用 React.memo 包裹组件（可选）
- [ ] 避免在渲染函数中创建新组件

## 回滚策略
