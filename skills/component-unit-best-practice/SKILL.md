# 组件单元（Component Unit）最佳实践

## 使用说明

1. 阅读 [目录结构与规范](references/standard.md)，了解 Component Unit 的标准文件夹布局
2. 对照 [检查清单](references/checklist.md) 逐项验证当前组件文件夹
3. 修复所有不符合规范的项目后，重新执行清单验证

**重要：** 组件、单元测试、Storybook 故事三者缺一不可；详细规范见参考文件
