# 技能创建器

## 使用说明

1. 阅读 [skill-initialization-guide.md](references/skill-initialization-guide.md) 了解 Skill 结构与核心原则
2. 参考 [workflows.md](references/workflows.md) 了解创建/更新流程
3. 遵循 [skill-packaging-guide.md](references/skill-packaging-guide.md) 完成打包规范
4. 使用 [checklist.md](references/checklist.md) 验证创建/更新结果

**重要：** SKILL.md 主体保持极简，详细内容全部放入 `references/`；完成后强制触发 `skill-best-practice` 检查
