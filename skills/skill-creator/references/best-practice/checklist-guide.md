# Best Practice Skill — Checklist 规范指南

本文件定义：在创建任何 **best-practice 类技能**时，`references/checklist.md` 的写法标准与 SKILL.md 的引用要求。

---

## 强制文件：`references/checklist.md`

所有 best-practice 技能**必须**在 `references/` 目录下创建 `checklist.md`，且该文件必须满足下列标准。

---

## 一、文件结构规范

### 1.1 固定开头

checklist.md 第一行必须是标准标题，第二段必须是执行规则声明：

```
# {Skill Name} 最佳实践检查清单

执行规则：**逐项勾选，若有任何一项为 ❌，必须修正后重新检查，不得跳过。**
```

### 1.2 大节与小节结构

- 大节用中文编号（一、二、三……），格式：`## 一、{大类名称}检查`
- 当一个大节下有多个维度时，**必须拆分小节**，格式：`### 1.1 {维度名称}`
- 每个大节对应一个独立质量维度（命名、文件结构、内容规范……），不得把不相关的检查项归入同一大节

### 1.3 需要覆盖的检查维度

| 检查维度 | 说明 | 是否强制 |
|---------|------|---------|
| 文件层面检查 | 文件命名规范、必需文件存在、禁止文件、空目录（适用于检查对象为目录/技能整体的情况） | 视场景而定 |
| 命名/格式检查 | 变量名、字段名、方法名规范 | ✅ 强制 |
| 内容规范检查 | 规则描述完整性、唯一映射原则 | ✅ 强制 |
| Bad Case 确认 | 明确列出所有不得出现的反模式 | ✅ 强制 |
| ⚠️ 强制后置步骤 | AI 执行完毕后必做的后续动作（如触发另一技能、更新注册表） | 视场景而定 |

> **说明**：「文件层面检查」的覆盖深度取决于检查对象。  
> - 检查对象是**目录/技能整体**（如 skill-creator）→ 必须覆盖「必需文件/禁止文件/空目录/双向引用一致性」  
> - 检查对象是**单个代码文件**（如 dao-best-practice 检查单个 DAO）→ 只需覆盖文件命名/位置规范即可

---

## 二、检查项写法要求

**每条检查项必须满足「唯一映射原则」：**

> 该条规则对应的正确写法是唯一的，不存在模糊地带；AI 可以纯文本搜索验证。

### ❌ 不合格示例（抽象、无法验证）

```
- [ ] 命名要规范
- [ ] 表单是独立沙盒
- [ ] 代码要有类型安全
```

### ✅ 合格示例（具体、可验证、含正反例）

```
- [ ] ✅ 表名最后一个名词为复数（`user` → 必须改为 `users`）
- [ ] ✅ 从 `zod/v4` 导入 Zod，严禁 `import { z } from "zod"`
- [ ] ❌ 严禁在 Service 层直接 `import { db } from "@/db"`（事务场景除外）
```

### 数值阈值要求

涉及长度、行数、数量限制时，**必须**给出精确数值：

```
- [ ] ✅ description 长度在 100–1024 字符之间
- [ ] ✅ SKILL.md 主体不超过 500 行
- [ ] ✅ name 长度 ≤ 64 字符
```

---

## 三、文件层面检查节（按场景决定深度）

文件层面检查的覆盖深度由被检查对象决定：

**检查对象为目录/技能整体时**，必须覆盖以下全部内容：
- **必需文件**：哪些文件必须存在及其命名规则
- **禁止文件**：哪些文件不得出现（临时文件、辅助文档等）
- **空目录**：是否存在无内容的空目录
- **双向引用一致性**：references/ 中的文件是否都被 SKILL.md 引用，SKILL.md 引用的文件是否都存在

**检查对象为单个代码文件时**，只需覆盖：
- 文件位置与命名（路径规范、命名格式）
- 必要的顶层导出格式

## 四、强制后置步骤节（可选）

checklist 最后一个大节可以选择添加 `## {末尾编号}、⚠️ {动作名称}（强制后置步骤）`，明确 AI 完成该技能任务后必须再做什么（如触发另一个技能、更新 README.md、注册到某表格等）。

示例格式：

```
## 六、⚠️ 仓库注册检查（强制后置步骤）

- [ ] ✅ 已确认：新技能是否已添加到 README.md 的技能表格中？
  - **否** → 必须在 `skills/` 表格补充记录，格式：`| [skill-name](skills/skill-name/) | 描述 |`
  - **是** → 确认链接路径和描述与 SKILL.md description 保持一致
```

---

## 五、SKILL.md 引用要求

在 SKILL.md 的资源索引中，checklist 必须排在首位并标注「**强制执行**」，且说明在哪个步骤读取：

```markdown
## 资源索引

- **检查清单（强制执行）**：见 [references/checklist.md](references/checklist.md)（每次生成或审查后必须逐项勾选）
- ...其他参考文件
```

同时在关键步骤处（如"完成后"、"重构后"）添加强制提示：

```markdown
**重要：** 调用完毕技能后，强制查看 [检查清单](references/checklist.md)，并确保返回的内容完全匹配清单中的所有项目。
```

---

## 六、AI 执行要求

在输出最终代码或审查结论前，AI 必须：

1. 读取 `references/checklist.md`
2. 按大节顺序逐项显式勾选（在输出中展示勾选过程，不得静默跳过）
3. 确认所有 ✅ 项满足、所有 ❌ Bad Case 不存在、所有数值阈值符合
4. 若有任何一项未通过 → 先修正 → 再重新从第一项开始勾选 → 全部通过后才允许输出结论
