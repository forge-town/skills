# 技能打包指南

此指南提供将技能目录打包成可分发 `.skill` 文件的说明。

## 概述

技能打包将技能目录压缩成单个 `.skill` 文件（实际上是 ZIP 格式），便于分发和安装。

## 先决条件

在打包之前，确保技能满足以下要求：

1. 技能目录存在且包含有效的 `SKILL.md` 文件
2. 技能已通过验证（参见 `skill-validation-guide.md`）
3. 所有必需的文件都存在

## 打包步骤

### 步骤 1: 验证技能

在打包之前，始终验证技能结构：

```bash
# 使用验证指南检查技能
# 确保所有验证检查都通过
```

### 步骤 2: 确定输出位置

选择 `.skill` 文件的输出目录：
- 默认：当前工作目录
- 自定义：指定输出目录（如 `./dist` 或 `packages/`）

### 步骤 3: 创建 .skill 文件

手动创建 ZIP 文件：

1. 导航到技能目录的父目录
2. 选择技能目录中的所有文件
3. 创建 ZIP 压缩文件，命名为 `{skill-name}.skill`
4. 确保使用 DEFLATE 压缩

**示例结构：**
```
my-skill.skill (ZIP 文件)
├── my-skill/
│   ├── SKILL.md
│   ├── scripts/
│   │   └── example.py
│   └── references/
│       └── code_examples.md
```

### 步骤 4: 验证打包结果

创建 `.skill` 文件后：

1. 检查文件是否成功创建
2. 验证文件大小合理
3. 可选：解压文件以确认内容完整

## 故障排除

### 常见问题

**验证失败：**
- 在打包前修复所有验证错误
- 确保 `SKILL.md` 格式正确

**权限错误：**
- 确保对输出目录有写权限
- 检查文件锁定或访问冲突

**文件大小过大：**
- 考虑移除不必要的资源文件
- 压缩大型参考文档

## 分发

打包的 `.skill` 文件可以：
- 通过文件共享分发
- 上传到技能仓库
- 包含在项目中作为依赖

## 安装打包的技能

要安装 `.skill` 文件：
1. 解压 ZIP 文件到适当的技能目录
2. 验证安装的技能结构
3. 测试技能功能
