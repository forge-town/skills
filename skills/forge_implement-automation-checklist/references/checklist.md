# Code Check Script 执行确认清单

执行规则：**脚本完成后逐项确认**

---

## 一、框架搭建

- [ ] 已创建项目结构和 package.json
- [ ] 已配置文件扫描（glob 模式、排除规则）
- [ ] 已搭建 AST 解析（如需要）
- [ ] 已实现报告格式化器

---

## 二、规则实现

- [ ] 每个 P0 规则都有完整实现
- [ ] 规则有明确的名字和错误消息
- [ ] 规则返回精确的行号/列号
- [ ] 规则处理边界情况（无崩溃）

---

## 三、测试覆盖

- [ ] 每个规则都有 Good Case（不触发错误）
- [ ] 每个规则都有 Bad Case（触发预期错误）
- [ ] 测试覆盖了边界情况
- [ ] 所有测试通过

---

## 四、集成验证

- [ ] 脚本在目标项目可运行
- [ ] 扫描结果正确（无漏报、无大量误报）
- [ ] 性能可接受（大型项目不超时）
- [ ] 有清晰的 CLI 使用说明

---

## 五、交付物

- [ ] 可运行的脚本代码
- [ ] README 使用文档
- [ ] 好/坏示例文件
- [ ] 与 plan-check-script 方案的对比（实现/未实现项）

---

## Bad Case 确认（不得出现）

- [ ] ❌ 脚本无法运行（缺少依赖、语法错误）
- [ ] ❌ 规则实现与方案设计不符
- [ ] ❌ 无测试用例，无法验证正确性
- [ ] ❌ 扫描结果有大量误报
- [ ] ❌ 缺少使用文档
