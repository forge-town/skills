# Linear Issue 查询完成清单

执行完毕后逐项确认；任一未满足项修正或在结果中明确披露。

- [ ] 已使用目标工作区的用户自装 MCP，并确认项目与筛选范围（如 已确认的目标工作区与项目；反例：跨工作区混查）。
- [ ] 已完成列表分页与去重，或明确披露缺失页（如 hasNextPage=false；反例：limit=100 就宣称完整）。
- [ ] 已按真实状态筛选，未把 In Review 当 Done 或 In Progress（如 statusType=completed 才排除完成项）。
- [ ] 已按产品一级模块与实际 labels 分组且每条只计一次（如 Agent；缺标进“未分类”，反例：根据标题 [Agent] 补造标签）。
- [ ] 已逐条对应五列与真实 URL，类型来自实际工作类型标签（如 `COD-123` 与该记录返回的真实 URL、Bug、In Review、已核实成员；缺类型写“未标注”，assignee=null 写“未分配”）。
- [ ] 已核对各组行数之和等于唯一 Issue 总数（如 9+2+1=12 仅是计数示例，不得复用为实时数据）。
- [ ] 已遵守只读范围，未调用 save_issue、save_issue_label 或评论写入工具，除非另有明确修改授权。
- [ ] 已保持中文简表与必要限制说明，未把工具失败写成零结果（如分页失败明确“未取全”，不写“当前无事项”）。
