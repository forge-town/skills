# Brainstorming 执行检查清单

执行过程中逐项确认：

- [ ] 已探索当前项目上下文，包括关键文件、文档和最近变更
- [ ] 已判断当前需求是否应拆分为多个独立子项目或子规格
- [ ] 已逐一提出澄清问题，覆盖目标、约束、边界和成功标准
- [ ] 已给出 2-3 种可行方案，并明确说明各自权衡与推荐方案
- [ ] 已将设计按复杂度分段呈现，并在继续前获得用户确认
- [ ] 已将批准后的设计写入 `docs/specs/YYYY-MM-DD-<topic>-design.md`
- [ ] 已完成规格自审，确认无占位符、歧义、矛盾和越界实现
- [ ] 已要求用户审阅规格文档，并在通过后转入 `writing-plans`
