# Introspect Best Practice 自检清单

执行规则：**逐项勾选，深入挖掘，不得浅尝辄止**

---

## 一、假设挖掘（已挑战的假设）

- [ ] 已识别 3+ 个规范背后的隐含假设
- [ ] 已验证每个假设在目标项目中的适用性
- [ ] 已标记不适用的假设

---

## 二、盲区扫描（已发现的盲区）

- [ ] 已发现 2+ 个规范未覆盖的边界场景
- [ ] 已发现 1+ 个过度设计的条款
- [ ] 已检查规范内部的自我矛盾
- [ ] 已评估规范在不同规模项目中的适用性

---

## 三、成本收益分析（已完成）

- [ ] 已评估每条规则的学习成本
- [ ] 已评估每条规则的执行成本
- [ ] 已评估每条规则的长期维护成本
- [ ] 已标记成本 > 收益的规则

---

## 四、替代方案探索（已探索）

- [ ] 已为 2+ 条规则提供替代方案
- [ ] 已考虑"不做"的可能性
- [ ] 已考虑分层/分级的规范方式

---

## 五、反思报告质量（已验证）

- [ ] 报告包含具体的盲区描述（非泛泛而谈）
- [ ] 报告包含可操作的改进建议
- [ ] 报告识别了需要废弃的具体规则
- [ ] 报告新增的建议规则解决了发现的盲区

---

## Bad Case 确认（反思过程中不得出现）

- [ ] ❌ 没有停留在表面，深入挖掘了隐含假设
- [ ] ❌ 没有全盘否定或全盘肯定，有批判性思考
- [ ] ❌ 没有遗漏成本分析
- [ ] ❌ 提出的改进建议具体可行，非空泛概念
