# Checklist 规范检查完成清单

执行完毕后逐项确认（规则定义见 `forge_checklist-best-practice`）：

- [ ] 目标目录已扫描，所有 `checklist.md` 文件已识别
- [ ] 每个文件已判断类型（规范 Checklist / 操作完成 Checklist）
- [ ] 可判定性已检查：无模糊表述条目（"应该"、"需要"、"建议"）
- [ ] 示例完整性已检查：每条规则至少有一个正确或错误示例
- [ ] 规范 Checklist 额外检查：编号格式、Bad Case 节存在与否
- [ ] 操作完成 Checklist 额外检查：条目数量（5-8 条）、动作导向语态
- [ ] 输出报告已生成（含通过/违规文件列表及修复建议）
