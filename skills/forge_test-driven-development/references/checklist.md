# TDD 执行检查清单

执行过程中逐项确认：

- [ ] 在编写任何生产代码前，已经先写下能描述目标行为的测试
- [ ] 已实际运行测试并看到失败结果，而不是只凭推断认为它会失败
- [ ] 失败原因与目标行为直接相关，而不是环境、语法或无关依赖导致
- [ ] 当前只编写满足该失败测试所需的最小生产代码，没有顺手扩展额外功能
- [ ] 已重新运行测试并确认目标测试通过，且未引入新的失败项
- [ ] 已在通过后完成必要重构，并再次运行测试确认行为保持不变
- [ ] 已覆盖新增功能、修复缺陷或回归场景的关键边界条件
- [ ] 已避免先写代码再补测试，整个过程保持 Red-Green-Refactor 顺序
