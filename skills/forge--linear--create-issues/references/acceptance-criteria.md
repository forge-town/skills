# 验收填写

以统一字段契约和 executable-acceptance.md 为准。BR 写一类场景的通用约定，AC 写具体样本和预期，关联必须有效；编号由表单分配，不自造另一套代号。

Given 逐行列执行前必要状态，不写先做什么再做什么。When 填确切输入和操作，Then 填具体返回内容、字段值或界面结果；不能只写“正确回答”“正常处理”。步骤中写清目标/控件、字面输入及逐步检查，缺真实入口、身份或固定样本就列待补。

实际执行状态默认未记录；只有真实运行后才填实际结果和可访问证据。结构校验通过不等于产品验收通过。不能用局部技术验证冒充完整业务验收。

不展示测试实现类型标签。新修改的业务标准和案例必须先填表单，再重新生成，不在 issue.md 手工追加。
