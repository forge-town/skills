# 复核 Linear 验收完成清单

执行完毕后逐项确认；只读范围内的发布/状态项注明未执行，不伪装为已发布。

- [ ] 已读取正确 Issue、原 Task/AC 和本轮验收提交（例：同一版本的评论；反例：把旧版通过用于新版）。
- [ ] 已核对实际 reviewer 身份、Agent 委托范围和本次授权（例：记录 Agent 复测；反例：冒称某位同事已签字）。
- [ ] 已逐项填写固定输入、具体预期、本次实际输出及证据（例：实际解析序列；反例：仅写“测试通过”）。
- [ ] 已按任务性质验证真实交付且注明环境版本（例：微信实际收图；反例：拿模拟回执代替手机验收）。
- [ ] 已区分通过、未通过和未验证，并正确汇总（例：缺凭据为未验证；反例：无法测试仍判通过）。
- [ ] 已保留差异、范围建议和历史记录，未擅改原标准或被测代码（例：反馈到 AC-02；反例：修完再冒充独立复核）。
- [ ] 已按授权回读评论、证据与状态，结果不明先查重（例：完整通过再 Done；反例：评论超时重复提及）。
- [ ] 已报告真实结论、执行范围及缺口（例：本地复核报告尚未发布；反例：未回评却称 Issue 已关闭）。
