# 提交 Linear 验收

完成工作和自验后，在对应 Issue 评论中留下可复核的证据并 @ 实际 reviewer，提交到 In Review；reviewer 确认通过后才进入 Done。

- 开始时读取 [执行流程](references/workflow.md)，核对授权、Issue、验收范围和 reviewer。
- 整理评论时读取 [评论模板](references/comment-template.md)，逐项填写输入、预期输出、实际输出和证据。
- 发布与回读后按 [完成清单](references/checklist.md) 检查，准确报告草稿、已提交评审或经 reviewer 确认通过的结果。

本技能负责既有 Issue 的验收交接，不重新定义产品范围。仅要求理解、起草或检查时保持只读；创建本技能本身不授权发送评论或修改任何 Issue。
