# 补录完成清单

执行后逐项确认；草稿或待确认条目不得记为已写入。

- [ ] 已核对当前 worktree/HEAD 与 staged、unstaged、untracked 范围；工作区干净时采用本会话明确的 PR，不混入其他发布历史。
- [ ] 已读相关 Issue 正文及评论，检索包含 Done、取消及可查归档项，不仅查 open 或标题。
- [ ] 每组业务改动只设一个主计点项，已记录同批工作不重复创建、评论或计时。
- [ ] 时长及来源清楚；缺少精确计时时已默认按 Git 与会话回顾估算，未重复询问估算授权，未将提交跨度、代码量或机器等待当连续开发工时。
- [ ] 已逐 Issue 累计后取整并写入原生 estimate，以投入替换计划点数；两段 30 分钟为 1 点，原计划 8 点不当作已投入 8 小时。
- [ ] 状态反映实际完成情况；已完成且必要自验通过直接 Done，未完成写剩余项，不额外设置 reviewer 门槛，也不一律 Done。
- [ ] 新建及复用项均分配给核对后的 PR 开发者；当前用户开发的 PR assign 当前用户，不使用机器人身份或沿用空负责人。
- [ ] 写入前核对并发修改；超时先回读再重试，部分成功分别记录。
- [ ] 已回读正文/评论、estimate、状态、assignee 和证据，最终清单有真实链接、来源和实际结果，失败及缺口未冒充成功。
- [ ] 未擅自提交/清理代码、合并、部署、调整 Cycle、发送其他渠道消息或伪造历史创建/完成时间。
