# Linear 技能迁入验证

## 范围

迁入八个个人实体 Skill：写法、表单、创建、规格审查、查询、提交验收、独立复核与工作补录。实际文件契约为 v18；转交记录的 v13 和历史浏览器证据属于早期快照，本次以当前实体源为准。

个人 create-linear-issues / backfill-linear-issues 在仓库分别命名为 forge--linear--create-issues / forge--linear--backfill-issues。脚本名称转为中划线，相关 import、CLI 文档及测试同步。第三方原始版权文件名保持原样。检查器支持 backfill 动词。

查询、提交验收和独立复核的当前源与 main 已有内容一致，因此没有制造无意义差异；它们仍纳入八技能分发包。个人目录、已禁用的旧入口和软链接配置均未修改。plan-linear-cycle、Vault 目录迁移、飞书文档与 PR brief 技能不纳入本 PR。

## 行为

创建与规格审查共享表单定义及生成器；原生属性和正文分开，摘要保留三项，背景可保留原意见和截图。任务与案例采用前提条件／操作／预期结果，案例关联任务；必要状态列表与具体输入仍保留。实际 v18 不再生成重复业务规则、用户流程、执行元信息、参考资料或完成条件章。历史数据归档供迁移核对，不静默丢弃。

正文须逐字来自当前表单，未知字段拒绝，正文被改写时校验失败。创建的额外视频、规格与形式化材料不覆盖正文源。通用能力未增加微信原生操作分类。验收交接留下逐项证据并提及实际 reviewer，独立复核不以自验替代；补录先查重，按累计实际投入向上取整计点，并如实记录估算依据。
