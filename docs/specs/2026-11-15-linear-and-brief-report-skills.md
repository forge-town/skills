# Linear 技能与工作简报

## 已确认范围

保留既有五个核心技能，新增：

- forge--linear--query-issues
- forge--linear--submit-acceptance
- forge--linear--review-acceptance
- forge--write-brief-report

只有 Linear 使用二级范畴，其他技能保持平铺；不恢复此前排除的编码、写作润色、文件修订、PDF 与会话接手技能。

## 内容约定

Linear 查询默认只读，按真实项目模块展示。提交验收记录原 AC 的输入、预期、实际输出及证据，按明确授权交接 reviewer。复核独立验证，不冒充人类 reviewer，不把未验证当通过。三个技能只使用用户自装的对应 Linear MCP，安装本技能不授权实际写入。

工作简报默认汇总用户本地当天从零点到核验时刻的工作。给出具体日期或时间范围时，以该时段为准，按事件实际发生时间筛选；完整日期范围包含结束日期，跨日不强制拆成多篇日报。按事项去重，区间外完成状态不能倒灌，尚未到来的工作不能计入。

默认在对话交付正文；文件产物放项目 docs/。不依赖飞书管理技能，不自动发布或发送。

## 实现与验证

复用本机四个技能的有效内容，统一元数据与名称，清除具体项目标签表、历史人物默认值与未收录依赖。更新 README、命名约定、检查器及两层命名的正反例测试。

验证静态命名、资源、README、语法及测试；另人工核对默认日报、指定单日、多日、跨日、未来截止和各 Linear 授权边界。真实 Linear 查询、评论、上传与状态流转需在实际使用时验证，本次不操作。
